System Architecture & Technical Specifications

Comprehensive explanation of dual-layer cryptography and pixel matrix modulation.
Layer 1: Cryptography (AES-256-GCM)

Uses Galois/Counter Mode (GCM) providing authenticated encryption (AEAD) with 128-bit authentication tags. Key derived via PBKDF2 with 100,000 SHA-256 rounds to guarantee resistance against GPU brute-forcing.

Layer 2: Steganography (LSB Modulation)

Replaces the Least Significant Bit of RGB pixel channels (0-255). Changing bit 0 modifies pixel intensity by at most ±1 shade, mathematically imperceptible to the Human Visual System (HVS).

Frequently Asked Viva Questions & Answers:

Specification: Cryptography conceals the content of the data, but reveals the presence of an encrypted payload (which draws eavesdropper suspicion). Steganography conceals the presence of communication by using an ordinary photo carrier. PixelCrypt enforces Defense-in-Depth: even if carrier steganography is suspected, the data is protected by military-grade AES-256-GCM.

Specification: JPEG uses lossy compression (Discrete Cosine Transform and quantization) which discards high-frequency pixel details, irreversibly destroying LSB bit modifications upon file save. PNG uses lossless compression (DEFLATE algorithm), guaranteeing 100% bit-exact pixel reproduction.

Specification: Verified using two standard image quality metrics: Mean Squared Error (MSE) and Peak Signal-to-Noise Ratio (PSNR) in decibels (dB). In PixelCrypt, PSNR consistently exceeds 65 to 80 dB (the international threshold for human visual imperceptibility is >50 dB).
